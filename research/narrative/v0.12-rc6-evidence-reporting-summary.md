# v0.12.0-rc6 evidence-reporting summary

RC6 is a reporting-only release over the completed RC5 benchmark. It does not rerun models and does not relabel RC5 observations as RC6 evidence. Before rendering, the new offline command verifies the checkpoint schema and version, the frozen manifest hash, and the size and SHA-256 of all 171 recorded artifacts.

The explanatory report separates two legitimate denominators. The balanced cross-model cohort contains fourteen configuration-conformant full campaigns and 3,360 evaluable episodes. It recorded 0 protected violations, 2,203 protected-workflow successes and 1,226 episodes with attack-added diagnostic events. The safety-accounting view contains all 4,299 distinct preflight, qualification, screening and full executions; all were evaluable, with 0 observed protected violations and 0 target failures. DeepSeek-R1-Distill-Llama-8B stopped at the reasoning-off configuration gate and has no inferred full score.

The one-page summary now explains the protocol, formulas and a worked attack-to-verifier trace before presenting the model table. The full report adds stage gates, paired-control outcomes, all twenty attack objectives, and one deterministic sanitized example for each comparable model. Public examples omit prompts, arguments, results, effect attributes, synthetic secret values and detailed invariant messages. They are illustrative traces, not frequency estimates.

No authorization, policy, approval, information-flow, MCP, protected contract, independent effect verifier or terminal reward semantics changed. VAIS still produces no composite security score and uses no AI judge. Zero violations in this run is bounded evidence only; it is not a proof of universal security or noninterference.

The next empirical work is to repeat selected campaigns for stability, evaluate the DeepSeek model in a separately labeled reasoning-enabled cohort, and seek an independent reproduction with separately preserved runtime and model identity.
