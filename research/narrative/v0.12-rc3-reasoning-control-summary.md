# VAIS v0.12.0-rc3 reasoning-control summary

## Outcome

RC3 corrects a benchmark-configuration defect without changing VAIS security enforcement or reward semantics. The LM Studio target and adaptive-attacker paths now request non-thinking inference with `reasoning_effort=none`. Observed reasoning tokens and characters remain the conformance authority after generation.

## Triggering observation

The RC2 Qwen3-0.6B Q4_K_M preflight completed one adaptive episode and six valid target generations, but recorded 2,043 reasoning tokens while labeled reasoning-off. The process exited nonzero under the predeclared mismatch gate. The run observed no protected invariant violation and no target failure, while protected workflow utility failed in both matched traces. Because the configuration was nonconforming, none of those measurements is promoted to an official cross-model row.

## Control selection

A same-runtime minimal API probe produced zero observed reasoning with `reasoning_effort=none`. The value `off` was rejected with HTTP 400. Appending `/no_think` also suppressed reasoning, but was rejected for the benchmark because prompt mutation would alter the experimental input across targets. The legacy `chat_template_kwargs.enable_thinking=false` request remains available only on the generic OpenAI-compatible adapter; it is no longer used by LM Studio-specific adapters.

## Preserved boundaries

- The reference monitor, policy, approvals, information-flow tracking, tenant isolation and effect execution are unchanged.
- The independent protected-effect verifier and terminal security reward are unchanged.
- A target failure remains unevaluated security evidence.
- A reasoning mismatch remains a configuration failure, not a security reward or a protected invariant violation.
- Request acceptance is never treated as proof of conformance.

## Limitation

The corrected request is directly verified only for the recorded LM Studio runtime and bounded Qwen3-0.6B probe. Other model templates or runtime versions may reject or ignore it. Preflight and observed-reasoning gates therefore remain mandatory before qualification, screening or full campaigns.
