# VAIS v0.12.0-rc2 benchmark-protocol summary

## Outcome

RC2 hardens experiment validity without changing the VAIS security thesis, reference monitor, independent protected-effect verifier, or terminal reward. A protected invariant violation remains the only terminal security reward of 1. Target failure and reasoning-mode mismatch remain separate experiment-health outcomes.

## Material RC1 observations

- Qwen3.5-9B Q4_K_M completed the bounded 60-episode RC1 screen with 60 evaluable episodes, zero observed protected invariant violations, zero target failures, zero observed reasoning tokens, and protected workflow utility in 51 episodes. Ten episodes contained attack-added policy events without an observed protected effect or attack-objective success.
- Gemma-4-12B Q4_K_M completed 59 evaluable episodes out of 60 in its bounded RC1 screen with zero observed protected invariant violations, one target failure, 161,660 observed reasoning tokens, and protected workflow utility in 51 evaluable episodes. Its reasoning-off label was nonconforming.
- Repeating an RC1 command with the same output paths overwrote the prior artifacts.
- RC1 report aggregation did not normalize the `lmstudio:` prefix used by real adaptive summaries.

These observations are bounded RC1 qualification evidence. They are not official RC2 full-campaign rows and do not establish universal security.

## RC2 decisions

- Add a one-episode preflight before qualification, screening, and full campaigns.
- Request the best-effort non-thinking template switch, record the request, and derive conformance from observed reasoning activity.
- Fail with a distinct exit status on reasoning mismatch or target failure; neither condition changes the security reward.
- Refuse experiment-artifact overwrite unless the operator explicitly passes `--overwrite`.
- Accept only frozen-panel target aliases, reject off-panel summaries and framework mismatches, and require stage completeness before marking a row completed.
- Replace Qwen3-8B with Qwen3.5-9B before official RC2 runs while retaining the four-Qwen panel limit.

## Verification

The source suite contains 191 passing tests after the RC2 changes. Dedicated regressions cover reasoning mismatch derivation, disable-request metadata, output no-clobber behavior, prefixed target matching, nonconforming report state, off-panel rejection, and screening-versus-full stage separation.

## Remaining limitations

The OpenAI-compatible LM Studio path still uses a model-specific best-effort chat-template hint. RC2 detects nonconformance after generation; it does not claim that this hint is an enforceable native reasoning control. A native LM Studio adapter remains future work. The public report stays pending until configuration-conformant RC2 full campaigns are executed.

The current portable tree rebuilds the evidence database but omits some historical local-model result artifacts. Its strict doctor therefore fails closed with 23 unexpected unresolved references and zero hash mismatches unless those historical roots are supplied; this is recorded as LIM-018 rather than hidden as a successful integrity pass.
