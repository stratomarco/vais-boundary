# RC8 freeze of the completed RC7 benchmark

RC8 is a packaging and evidence-freeze release. It does not relabel the completed campaign: the benchmark evidence remains `0.12.0rc7`, and the public report records both evidence and renderer identity.

The immutable RC7 checkpoint contains 180 artifact records. Offline verification checked the manifest, checkpoint, artifact sizes and every recorded SHA-256 before rendering the committed report. The run attempted 4,605 distinct staged episodes and evaluated 4,603. No protected invariant violation was observed. Fourteen models completed the full 240-episode stage; SmolLM3-3B stopped at the full-stage experiment-validity gate after two target generations remained truncated and non-JSON after the uniform 4,096-token retry.

DeepSeek-R1-Distill-Llama-8B completed 240/240 full episodes in the separately labeled native-reasoning cohort with observed reasoning required. This resolves the earlier unsupported reasoning-off configuration for the recorded model/runtime, but it does not make its utility, latency, token use or attack-added rate directly comparable to reasoning-off rows.

## SmolLM follow-up

A separate diagnostic repeated `attack-18` and `attack-19` with the original 2,048-token first attempt and one auditable retry raised from 4,096 to 7,168 tokens. The first attempt remained in generation metadata. Of 24 episodes, 23 were evaluable and one new `attack-19` generation exhausted the 7,168-token retry and remained non-JSON. The two original failure positions did not fail in the repeat.

This single repeat does not estimate a failure probability or establish a universal model property. It does establish that simply increasing the retry ceiling did not make this recorded model/runtime reliably evaluable. RC8 therefore preserves the common 4,096-token panel budget and the original SmolLM gate failure. It does not replace failed RC7 episodes with later diagnostic outcomes.

## Claim boundary

The results apply only to the recorded model keys, Q4_K_M selections, reasoning profiles, LM Studio runtime, RTX 4080 Super 16 GB execution boundary, 8,192-token context, prompts, scenarios and budgets. A target failure is unevaluated, never successful defense. Zero observed protected violations in a finite run is bounded negative evidence, not proof of universal security.
