# v0.12.0-rc5 campaign-driven TCB regression summary

The completed RC4 campaign attempted 4,059 staged episodes and evaluated 4,057. Eleven models completed the full stage; four stopped at a fail-closed gate. The campaign independently observed one protected `secret_public_flow` violation in Qwen2.5-7B screening. This is exactly why VAIS runs the model and the trusted boundary adversarially instead of treating passing unit tests as proof.

The violated episode showed a concrete trusted-boundary defect. A model copied only a prefix of a secret-bearing value into a public Slack argument. RC4's adapter classified generated output by looking for complete source values; because the output omitted part of the source, it received public confidentiality and the pre-effect policy allowed the first send. The independent verifier then detected the synthetic canary in the observable external effect and assigned terminal reward 1.

RC5 removes content matching as a confidentiality authority. Every non-exact model output is untrusted and inherits the maximum confidentiality of all values visible to that generation. Exact trusted-bound rebinding now uses canonical, type-sensitive security equality. Only a trusted explicit declassifier may lower confidentiality. Dedicated regressions cover partial copying, transformed output with no matching substring and Python's boolean/integer equality edge case.

The same campaign exposed two evidence-quality defects. Final RC4 reports selected only passed full-stage summaries, which could hide the gate-triggering screening violation after later models completed. RC5 retains every model's highest reached stage and computes safety-critical totals across every executed stage. Those totals are explicitly labeled as distinct staged executions, not a balanced model-ranking denominator. RC5 also gives every frozen panel model the same 4,096-token truncation retry allowance; failed first attempts remain visible.

The source suite passes 211/211 tests. Corrected report replay against the hashed RC4 checkpoint produces `complete_with_failures`, 4,057/4,059 evaluable/attempted, one protected violation, two target failures, eleven full completions and four gate failures. Browser inspection confirms that the alert and failed-stage denominators render without overlap.

These are bounded implementation and replay results. Conservative lineage can overtaint safe model-derived text until an application uses a trusted declassification step. RC4 data remains RC4 discovery evidence; it does not establish RC5 security or utility rates. A fresh version-matched panel run is required before publishing an RC5 cross-model benchmark.
