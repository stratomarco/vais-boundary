# VAIS Project History

VAIS evolved from a deterministic boundary prototype into a research framework for measuring the distinction between model compromise and system compromise.

- **v0.1:** provenance, task contracts, deterministic reference monitor, behavioral gate, sandbox effects and indirect-prompt-injection demo.
- **v0.2:** confidentiality, capability scopes, exact action approvals, declarative invariants and deterministic audit trail.
- **v0.3:** benchmark protocols, protected/unprotected execution, five initial attack scenarios, effect-based reward and CI regression gates.
- **v0.4:** real local-model integration through OpenAI-compatible structured output while preserving the model as proposal-only.
- **v0.5/v0.5.1:** research-grade generation status/denominators and the first major measurement correction: plan change -> security drift -> attack objective -> observable impact.
- **v0.6:** balanced 125-case static corpus.
- **v0.7:** explicit project philosophy plus MCP ingress/egress enforcement semantics.
- **v0.8/v0.8.1:** MCP-path empirical benchmark and directional drift correction, including off-objective security escalation.
- **v0.9.x:** stateful production-shaped incident-response reference system, matched controls, semantic pair deltas, declassification artifacts, tenant registry and normalized delegation authority.
- **v0.10:** adaptive verification with a frozen v0.9.3 security baseline and terminal reward tied only to independently observed protected invariant violation.
- **v0.11:** canonicalization, recursive immutability, scoped consume-once approvals, fail-closed policy arguments, audit chaining and MCP crash/retry hardening.
- **v0.12 RC1-RC4:** frozen diverse local-model panel, reasoning/runtime conformance gates, contextual reporting and fail-closed resumable automation.
- **v0.12 RC5:** campaign-driven TCB correction after RC4 exposed partial-copy secret lineage, plus failed-stage evidence retention and uniform truncation retry policy.
- **v0.12 RC6:** reporting-only renderer over verified RC5 evidence, with explicit methodology, formulas, paired outcomes, sanitized model-level examples and deterministic public artifacts.

The project thesis remained stable while measurement became progressively stricter: **assume model compromise, constrain consequence, verify effects.**
