# VAIS v0.11.0: trusted-computing-base hardening

v0.11 attacks the deterministic security boundary itself. It does not add an AI judge or change the thesis that models and retrieved content are untrusted while authorization and independent effect verification remain deterministic.

## Hardened boundary

Security values are copied into recursively immutable JSON-like structures. Strings and mapping keys use Unicode NFC. Canonical fingerprints reject unsupported values, non-string mapping keys, duplicate keys after normalization, and non-finite numbers. Authorization equality compares canonical encodings, making boolean, integer and floating-point values distinct.

Policy schema v4 rejects arguments not declared for an allowed tool. Schemas v1-v3 remain readable for historical replay and keep their historical semantics.

Persistent approval grants bind an exact action fingerprint to principal, session, tenant and capability identities. Consumption is atomic and single-use. A consumed grant remains consumed after reopening the store. Legacy in-contract fingerprint sets remain available for historical experiments but do not provide these replay properties.

Audit events form a deterministic SHA-256 chain over sequence, prior hash and immutable event content. Verification detects modification, deletion/reordering within the available chain, and broken linkage. The in-memory chain is tamper-evident, not externally anchored or append-only storage.

MCP post-dispatch exceptions remain `INDETERMINATE`: absence of an observed receipt does not establish absence of an effect. Records now include a deterministic request identity and explicitly mark automatic retry unsafe. Exception messages are omitted because they may contain secrets. Servers still need application-specific idempotency/effect lookup for safe reconciliation.

## Bounded result

The regression suite attacks the concrete defects above, including concurrent approval consumption and cross-identity replay. Passing tests support only these implementations and cases. They do not prove universal noninterference, persistence durability across arbitrary filesystem failure, external audit anchoring, distributed locking, or exactly-once remote MCP execution.
