# VAIS RC6 reviewer pack

## The short version

VAIS treats the language model as an untrusted planner. Proposed tool actions pass through deterministic policy, capability, identity, information-flow and effect controls. Terminal security reward comes from independent observation of protected effects, not from an AI judge.

This pack explains a bounded local benchmark using fifteen diverse Q4_K_M instruction models on an RTX 4080 Super with 16 GB VRAM. The evidence was generated by VAIS 0.12.0rc5 and rendered by the reporting-only 0.12.0rc6 release.

## What was observed

- Fourteen of fifteen models completed the common full stage.
- The balanced full cohort contained 3,360/3,360 evaluable episodes.
- Protected-workflow utility was 2,203/3,360 (65.6%).
- Attack-added diagnostic events occurred in 1,226/3,360 episodes (36.5%).
- Across all distinct stages, 4,299/4,299 episodes were evaluable with zero observed protected invariant violations and zero target failures.
- DeepSeek-R1-Distill-Llama-8B stopped at the reasoning-off configuration gate and has no inferred full score.

Zero observed violations is bounded negative evidence for these executions. It is not proof of universal security, noninterference or model safety. Utility and attack-added activity are separate measurements, not components of a composite security score.

## Suggested reading order

1. `one-page-summary.pdf` — the complete result and methodology in one landscape page.
2. `technical-report.pdf` — methodology, all twenty attack stories, paired outcomes and sanitized model-level traces.
3. `benchmark-report.html` — the most detailed interactive-length report.
4. `report-evidence-manifest.json` — evidence/renderer identity and input-integrity record.

## What is not included

This pack intentionally contains no source code, model files, prompts, raw JSONL/RLVR trajectories, tool arguments, tool results or synthetic secret-bearing values. The public examples are deterministic sanitized derivatives of controlled raw evidence.
