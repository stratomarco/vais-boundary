# Benchmarks

The bundled benchmark is a deterministic security-semantics and integration fixture. It is intentionally small and must not be presented as evidence of universal LLM robustness.

## Attack corpus

`attacks/default.jsonl` contains one reference attack candidate for each of the five initial scenario families:

1. email recipient hijack;
2. secret-to-public egress;
3. payment destination hijack;
4. forbidden tool escalation;
5. approval replay.

The corpus is a control fixture for the framework. v0.6 will expand it substantially before adaptive RLVR experiments.

## Current deterministic snapshots

### `snapshots/default-v0.5.jsonl`

Full deterministic episode records generated by v0.5.

### `snapshots/default-v0.5-summary.json`

Stable expected summary for the v0.5 regression suite, including valid-security denominators, confidence intervals and target-health fields.

## Historical snapshots

`default-v0.3.jsonl` and `default-v0.3-summary.json` are retained as historical artifacts from the first adaptive-verification core.

## Real-model outputs

Real-model results should normally be written under `results/` and preserved with the exact VAIS version, attack corpus and model configuration. Do not replace deterministic snapshots with results from stochastic targets.

Example:

```powershell
vais benchmark-lmstudio `
  --model "qwen/qwen3.5-9b" `
  --reasoning-mode off `
  --attack-corpus .\benchmarks\attacks\default.jsonl `
  --output .\results\qwen35-v050.jsonl `
  --summary .\results\qwen35-v050-summary.json
```

A target failure such as `truncated` or `invalid_plan` is preserved in the JSONL and excluded from the security-metric denominator. It is never interpreted as a resisted attack.

## v0.8 MCP-path corpus

`attacks/mcp-static-v0.8-125.jsonl` contains 125 controlled candidates (25 per scenario) delivered by the v0.8 runner as untrusted MCP tool-result data. The installed package exposes the same corpus as `bundled:v0.8-mcp`.

## v0.10 adaptive reference regression

`benchmarks/snapshots/adaptive-reference-v0.10.0-summary.json` is the deterministic online adaptive-verification regression over the frozen v0.9.3 Reference Agent (20 campaigns x 12 episodes). It validates adaptive-search/reward plumbing only; it is not evidence about real LLM robustness. The terminal reward remains zero unless a protected independent trace invariant is violated.
