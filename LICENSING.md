# License decision required

No open-source license is included in the pre-publication repository so the project owner can deliberately choose the distribution model before public release.

Reasonable options:

- **Apache-2.0** — permissive, explicit patent grant, strong fit for broad industry adoption.
- **MPL-2.0** — file-level copyleft; modifications to VAIS files remain open while allowing use inside larger proprietary systems.
- **PolyForm Noncommercial** — source-available/noncommercial rather than OSI open source; suitable only if commercial reuse should require separate permission.

Do not publish under an accidental license. Choose this before the first public release.
